## 五、BRAM Port B 连接要求

`laser_tx_core_0` 的 BRAM 接口已经补全为 Vivado 原生 BRAM Port B master 接口。

连接方式：

```text
blk_mem_gen_0/BRAM_PORTB → laser_tx_core_0/BRAM_PORTB
```

要求：

1. 如果当前 BD 中存在外部 `BRAM_PORTB_0`，请删除该 external interface port；
2. 保留 `blk_mem_gen_0/BRAM_PORTB`；
3. 将 `laser_tx_core_0/BRAM_PORTB` 直接接到 `blk_mem_gen_0/BRAM_PORTB`；
4. 不要额外给 `bram_we`、`bram_din` 接常量，因为 RTL 内部已经固定：

   * `bram_we = 4'b0000`
   * `bram_din = 32'd0`
5. 确认 Block Memory Generator 为 True Dual Port RAM；
6. Port B 数据宽度为 32 bit；
7. Port B 读延迟为 1；
8. Port A 继续连接 `axi_bram_ctrl_0/BRAM_PORTA`，供 PS 读写。

## 六、AXI GPIO 连接要求

`axi_gpio_0` 必须配置为双通道。

请在脚本中设置：

```text
Channel 1：All Outputs，width = 32
Channel 2：All Inputs，width = 32
```

连接方式：

```text
axi_gpio_0/gpio_io_o[31:0]       → laser_tx_core_0/gpio_ctrl[31:0]
laser_tx_core_0/gpio_status[31:0] → axi_gpio_0/gpio2_io_i[31:0]
```

如果当前 BD 中存在旧的外部端口 `gpio_rtl_0`，请删除。

GPIO bit 定义如下：

```text
gpio_ctrl[7:0]  = config_index
gpio_ctrl[8]    = apply_toggle
gpio_ctrl[9]    = enable
gpio_ctrl[10]   = soft_reset
gpio_ctrl[11]   = pattern_source_sel
                  0 = seed PRBS
                  1 = direct pattern
gpio_ctrl[12]   = direct_pattern_len_sel
                  0 = 63bit
                  1 = 127bit
```

注意：软件每次应用新配置时必须翻转 bit 8，而不是输出窄脉冲。


```text

```

## 十一、ILA 触发建议

请在 `ila_signal_map.md` 中写明以下触发建议：

1. 首次启动时，触发 `apply_toggle` 或 `cfg_update_pulse_tx`；
2. 观察 phase 边界时，触发 `acq_trig_out` 或 `phase_start_pulse_tx`；
3. 观察 gap 时，触发：

   ```text
   valid_mask != 64'hFFFF_FFFF_FFFF_FFFF
   ```
4. 如果想捕获纯 gap word，可设置：

   ```text
   gap_len_bits = 128
   ```

   这样至少会出现一个 `valid_mask = 64'h0` 的 word。

不要写 UDP，不要写 AD9528，不要写 GTX rate plan。

AXI GPIO 使用 Xilinx 官方 `XGpio` 驱动。

## 十三、BRAM 参数格式

每组配置占 32 字节：

```text
base = index * 32
```

写入格式：

```text
base + 0x00: seed[31:0]
base + 0x04: repeat_cycles[31:0]
base + 0x08: gap_cfg[31:0]
             gap_cfg[7:0]  = gap_len_bits
             gap_cfg[23:8] = insert_after
base + 0x0C: mode_cfg[31:0]
             mode_cfg[7:0] = prbs_order
             mode_cfg[8]   = phase_shift_en
             mode_cfg[9]   = loop_en
base + 0x10: pattern_low[31:0]
base + 0x14: pattern_mid[31:0]
base + 0x18: pattern_high[31:0]
base + 0x1C: pattern_top[31:0]
```

direct pattern 拼接方式：

```text
pattern_in[126:0] = {pattern_top[30:0], pattern_high, pattern_mid, pattern_low}
```

不要实现 128bit pattern。


```text

gap 纯 word 时 eom_out=0

gap 期间 acq_gate_out 保持高
```

```text
prbs_order = 6
repeat_cycles = 4
insert_after = 2
gap_len_bits = 5
phase_shift_en = 1
loop_en = 0
```

预期：

